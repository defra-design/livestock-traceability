{# The panel confirms the action submitted, not necessarily the whole movement. #} {% if movement.status == 'confirmed' %} {% call govukPanel({ titleText: "Whole movement confirmed" }) %} Movement {{ movement.id }} {% endcall %}

What happens next

Both keepers have agreed the movement details. No further confirmation is needed.

The movement record and the actions taken to confirm it remain available to view.

{% elif movement.status == 'changes' %} {% call govukPanel({ titleText: "Proposed changes submitted" }) %} Movement {{ movement.id }} {% endcall %}

What happens next

Your proposed changes have been recorded. The keeper who originally reported the movement will need to accept or dispute them.

The original movement report has not been overwritten. The whole movement is not yet confirmed.

{% elif movement.status == 'rejected' %} {% call govukPanel({ titleText: "Movement rejection submitted" }) %} Movement {{ movement.id }} {% endcall %}

What happens next

The keeper who reported the movement can review your reason for rejection and decide whether to correct, withdraw or dispute their report.

The original ON or OFF report remains recorded. The whole movement has not been confirmed or automatically cancelled.

{% elif movement.status == 'disputed' %} {% call govukPanel({ titleText: "Movement dispute submitted" }) %} Movement {{ movement.id }} {% endcall %}

What happens next

The disagreement has been recorded for BCMS to investigate and determine. Neither keeper's original declaration has been automatically overwritten.

The whole movement is not confirmed. BCMS may need more information from one or both keepers.

{% elif movement.status == 'withdrawn' %} {% call govukPanel({ titleText: "Movement report withdrawn" }) %} Movement {{ movement.id }} {% endcall %}

What happens next

This movement report is withdrawn and will not become a confirmed whole movement through the current review process.

The withdrawn report and its activity history have been retained. If cattle did move, you may still need to report the actual movement correctly.

{% elif movement.status == 'awaiting' %} {% call govukPanel({ titleText: "Corrected movement report submitted" }) %} Movement {{ movement.id }} {% endcall %}

What happens next

The corrected report has been sent for the other keeper to review and confirm.

The original movement reference and submission information have been retained, along with the correction in the activity history. The whole movement is not yet confirmed.

{% elif movement.status == 'unconfirmed' %} {% call govukPanel({ titleText: "Movement remains unconfirmed" }) %} Movement {{ movement.id }} {% endcall %}

What happens next

The original ON or OFF report is still recorded, but the opposing keeper has not confirmed the whole movement. It may need further review by BCMS.

{% else %} {% call govukPanel({ titleText: "Movement action recorded" }) %} Movement {{ movement.id }} {% endcall %}

The movement record has been updated. You can view its current status and activity history.

{% endif %}
