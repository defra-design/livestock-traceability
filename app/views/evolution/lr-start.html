Livestock reporting

This service replaces Cattle Tracing System (CTS) online.

Use this service to:

  • report births, deaths and movements
  • view your animal records
  • update your details

Before you start

To use this service you need a County Parish Holding (CPH) number.

If you do not have a CPH number, you'll need to set up as a livestock keeper first. When you're set up, you can create your account.

Sign in or create your account

If you already have an account, you will be able to sign in, or create one if you haven't already.
